1. Sobre o Sistema

O Conversor AFD foi criado para unificar batidas de ponto provenientes de diferentes fontes (relógios físicos que geram arquivo AFD, planilhas Excel/CSV) e permitir a correção e exportação destes dados em um formato padronizado.

2. Tela Inicial e Acessos

Na tela inicial você encontrará os botões de acesso aos módulos principais, dependendo do seu nível de permissão.

  • Gerenciar AFD: Acessa o painel principal de funcionários e batidas de ponto.
  • Gerenciar Usuários: Visível apenas para super administradores. Permite criar novos usuários ou redefinir senhas, além de conceder ou remover acesso ao sistema Conversor.
  • Logout: Encerra sua sessão com segurança.

3. Gestão de Funcionários

Ao clicar em "Gerenciar AFD", você é direcionado para a listagem de funcionários. O sistema oferece uma busca dinâmica (mínimo de 3 letras) por Nome, PIS, CPF ou Matrícula.

Filtros e Busca

Utilize a barra superior para pesquisar rapidamente. Você também pode filtrar funcionários por Grupo (ex: professores, administrativos).

Ações da Tabela

Na coluna "Ações", você encontra dois botões para cada funcionário:

  • Editar: Permite alterar os dados cadastrais e modificar a quais grupos o funcionário pertence.
  • Ver Ponto: Abre o calendário completo do mês selecionado com as batidas de ponto.

4. Gestão de Ponto

Na tela de Ver Ponto, você visualiza o calendário do mês inteiro para um funcionário específico.

Edição Manual

Se o funcionário esqueceu de bater o ponto ou o relógio falhou, você pode clicar em qualquer dia no calendário para editar as batidas. Os registros modificados manualmente receberão uma flag e não serão sobrescritos em importações futuras.

5. Importações de Dados

O sistema possui métodos robustos para importar dados em massa, economizando tempo. Todos esses recursos são acessíveis via botões na tela de listagem de funcionários.

Importar Funcionários

Importa um lote de funcionários através de um arquivo de texto. O arquivo deve seguir a estrutura sequencial (Matrícula, Nome, PIS, CPF - um por linha).

Importar Planilha (Ponto)

Importa batidas de ponto a partir de arquivos .xlsx ou .csv. O sistema cruza os dados baseado na coluna ID (que corresponde à Matrícula do funcionário) e a coluna Hora.

  • Dica: Você pode associar automaticamente todos os pontos importados a um Grupo específico, escolhendo se deseja adicionar o funcionário a este grupo ou substituir os grupos antigos dele.

Importar AFD (Ponto)

Lê o arquivo texto gerado diretamente pelos relógios de ponto físicos (formato AFD). Ele processa as linhas tipo 3 e vincula as batidas ao funcionário pelo PIS ou CPF.

6. Exportação de AFD

Após consolidar e corrigir os pontos, você precisa gerar o arquivo final.

Gerar AFD

Este botão permite exportar as batidas de ponto em formato AFD oficial (Arquivo Fonte de Dados). Você pode exportar:

  • Todos os registros dentro de um período.
  • Por Grupo Específico (ideal para separar arquivos por secretarias ou setores).
  • Por Funcionário Único.

7. Configurações Avançadas

Gerenciar Grupos

Permite criar, renomear e excluir grupos de funcionários. Quando um grupo é excluído, ele é automaticamente desvinculado de todos os funcionários que pertenciam a ele, mas os funcionários e seus pontos não são apagados.

Cadastros Ignorados

Conhecido como "Lista Negra". Se o relógio físico possui registros antigos de pessoas que não fazem mais parte do quadro, ou marcações de teste, você pode cadastrar o PIS, CPF ou Matrícula nesta tela.

Efeito: Qualquer importação futura (via AFD ou Planilha) vai simplesmente ignorar as batidas desses cadastros e pular para o próximo, sem exibir erros no terminal de importação.
